单机械臂 / 01

冗余机械臂数据驱动运动—力协同控制

研究模型未知冗余机械臂的数据驱动运动–力协同控制，实现轨迹跟踪与接触力稳定调节。

项目背景

  • 在精密装配、表面打磨和接触式检测等任务中，机械臂需兼顾轨迹跟踪精度与接触力稳定性，保障作业质量与安全。
  • 运动学模型不确定、环境刚度变化及外部扰动等因素易引起轨迹偏差、接触力波动和系统失稳。
  • 传统运动–力控制方法依赖准确的机器人模型和固定控制参数，难以适应模型误差与复杂接触环境。

主要工作

  • 完成末端六维力传感器的数据读取、坐标转换与实时反馈，将接触力测量信息引入闭环控制系统。
  • 设计数据驱动运动–力协同控制器，实现模型未知条件下的高精度轨迹跟踪与稳定接触力调节。
  • 基于 MATLAB、CoppeliaSim 和 UR5 实物平台开展仿真与接触实验，验证控制方法的跟踪精度、力响应性能及抗干扰能力。
力控制接触操作模糊自适应

单机械臂 / 02

模型未知冗余机械臂数据驱动运动控制

面向运动学模型不确定、传感噪声及外部扰动，研究不依赖精确模型的高精度轨迹跟踪控制方法。

项目背景

  • 冗余机械臂具有较高的运动自由度，传统控制方法通常依赖准确的运动学模型，难以适应模型未知或参数变化的情况。
  • 机械臂在实际运行中受到建模误差、传感噪声及外部扰动等因素影响，容易产生轨迹跟踪偏差，降低控制精度与稳定性。
  • 数据驱动控制需要根据实时运动数据更新模型，同时兼顾在线计算效率、算法收敛性及系统抗干扰能力。

主要工作

  • 提出 DZNN-QN 算法，将离散零化神经动力学与在线拟牛顿雅可比估计相结合，实现模型未知条件下的冗余机械臂高精度轨迹跟踪。
  • 设计 D²-FDRNN 模型，融合在线估计、模糊自适应控制与卡尔曼滤波，提高复杂扰动条件下的控制精度与鲁棒性。
  • 开展算法收敛性、闭环稳定性及噪声鲁棒性分析，完成控制参数设计与优化，为控制方法的有效性提供理论支撑。
  • 基于 Kinova 仿真平台与 UR5 实物机械臂开展轨迹跟踪实验，通过跟踪误差、收敛性能及抗干扰表现评估算法的有效性与工程适用性。

论文与专利

  • IEEE TIE｜A Novel Model-Free DZNN-QN Algorithm for Redundant Manipulator Control
  • IROS 2025｜Inverse-Free and Data-Driven Motion Tracking Control for Redundant Robot with Fuzzy Recurrent Neural Network
  • 专利｜一种冗余机械臂运动控制方法、计算机设备和存储介质
DZNN-QND²-FDRNN高精度抗干扰

多机械臂 / 01

双臂柔性线缆数据驱动形状控制

面向柔性线缆等复杂可变形对象，研究双机械臂协同条件下的形状建模、闭环控制及操作技能复用。

项目背景

  • 柔性线缆具有高维、强非线性及形状易变等特点，其形变受材料特性、操作方式及环境接触影响，难以建立准确的解析模型。
  • 面向柔性线缆装配与操作任务，双机械臂需协调末端运动与线缆形状变化，解决协同控制、形状调节及操作技能复用等问题。

主要工作

  • 基于 Koopman 算子与数据驱动学习方法，建立柔性线缆形状变化与双端夹爪运动之间的映射关系，构建线缆形状预测模型。
  • 研究双机械臂协同操作方法，设计基于形状反馈的闭环控制策略，实现柔性线缆的形状调节与末端协调运动。
  • 基于 MATLAB 与 MuJoCo 搭建双机械臂柔性线缆仿真平台，完成柔性体物理建模、数据采集、模型训练及预测误差分析。
  • 面向线缆张紧、拉直、形状变换及端点对齐等任务，设计基础操作技能与控制策略，构建可复用的柔性线缆操作技能库。
Koopman柔性物体操作双臂协同控制

无人机 / 01

四旋翼无人机轨迹规划与视觉定位控制

完成四旋翼无人机轨迹优化、三维自主避障、视觉定位及轨迹跟踪控制算法开发。

项目背景

  • 四旋翼无人机在自主巡航、环境探测及复杂场景作业中，需要在三维空间内规划安全、平滑且可执行的飞行轨迹。
  • 实际飞行过程中，视觉定位误差、环境扰动及控制参数变化等因素容易影响无人机的定位精度与飞行稳定性。
  • 无人机需综合考虑障碍物分布、飞行时间及动力学约束，实现高效路径规划、实时避障与稳定轨迹跟踪。

主要工作

  • 设计基于 Minimum-snap 的轨迹优化算法，综合考虑轨迹平滑性与飞行约束，实现四旋翼无人机平滑、可执行的轨迹生成。
  • 基于 A* 搜索算法开展三维路径规划，优化路径搜索策略与启发函数，实现复杂环境下的自主避障与路径优化。
  • 设计串级 PD 控制器，完成位置与姿态控制回路的解耦设计及参数调试，提高无人机轨迹跟踪精度与飞行稳定性。
  • 基于视觉 SLAM 开展无人机位姿估计与优化，改善复杂环境下的定位精度，为自主导航与闭环控制提供状态反馈。
  • 完成轨迹规划、视觉定位与飞行控制模块集成，解决异构数学库间的数据传递问题，保障系统稳定运行。
动力学建模轨迹规划SLAMPD控制

无人车 / 01

基于 Autoware 的巡检机器人自主导航与停障系统

基于 Autoware 完成巡检机器人的感知、定位、轨迹跟踪和安全停障系统开发，并完成实车验证。

项目背景

  • 面向机场、园区等实际应用场景，巡检机器人需要在复杂道路环境中实现自主导航、轨迹跟踪、障碍物检测与安全停障。
  • 自主导航系统涉及激光雷达、定位模块与线控底盘等多种设备，需要解决传感器标定、坐标变换及 Autoware 与底盘 ECU 之间的通信适配问题。
  • 实际道路存在曲率变化、动态障碍物及定位误差等因素，对轨迹跟踪精度、环境感知能力和运行安全性提出较高要求。

主要工作

  • 完成激光雷达与车体坐标系标定、ROS TF 坐标变换配置及点云数据处理，为机器人定位、环境感知与自主导航提供数据支持。
  • 基于 ROS 与 Autoware 搭建自主导航系统，完成 Autoware 与线控底盘 ECU 的通信接口适配，实现导航控制指令的传输与执行。
  • 设计基于 Pure Pursuit 的轨迹跟踪算法，根据车辆速度动态调整预瞄距离，提高不同车速及道路曲率条件下的轨迹跟踪稳定性。
  • 基于激光雷达点云欧几里得聚类实现障碍物检测，结合安全距离判断与停车控制策略，实现障碍物识别及自主安全停障。
  • 完成自主导航、轨迹跟踪和障碍物检测模块的集成调试，并开展实车测试，验证系统的运行稳定性与实际场景适用性。
自动驾驶激光雷达点云聚类障碍物检测

单片机 / 01

基于 MSP432 的嵌入式系统开发：循迹机器人与智能钟

围绕 MSP432P401R 开展嵌入式软硬件开发，完成循迹迷宫机器人与多功能智能钟的外设驱动、实时控制、交互设计及系统联调。

项目背景

  • 嵌入式系统需要在有限计算与硬件资源下完成传感器采集、执行器控制、实时任务调度和人机交互，对软硬件协同设计能力提出较高要求。
  • 循迹机器人需要根据红外传感器阵列实时识别直线、弯道与复杂路口，并通过电机控制完成巡线、转向和迷宫路径决策。
  • 智能钟需要协调实时时钟、OLED、按键、蜂鸣器和 LED 等外设，在保证计时准确性的同时实现多功能界面与可靠交互。

主要工作

  • 基于 MSP432P401R 完成 GPIO、PWM、定时器、中断及通信接口配置，搭建嵌入式外设驱动与应用程序框架。
  • 在 TI-RSLK 平台读取红外反射传感器阵列，结合有限状态机与左手法则实现黑白线循迹、路口识别、转向和迷宫自主行驶。
  • 针对轮速偏差、采样间隔和转弯时序开展参数调试，并利用板载 LED 显示不同路况与运行状态。
  • 集成 0.96 英寸 OLED、DS1302 实时时钟、按键、蜂鸣器和 LED，完成智能钟硬件连接、驱动开发及菜单式交互界面设计。
  • 基于 TimerA、Timer32 与按键中断实现世界时钟、12/24 小时切换、闹钟、秒表、倒计时及时间校准等功能，并完成整机联调与测试。
MSP432嵌入式 CGPIO / PWM定时器 / 中断OLED / DS1302有限状态机
